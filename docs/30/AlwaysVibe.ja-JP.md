# 神格化された「手作り時代」：我々はおおかた、ずっと Vibe の中で生きてきた

[English](AlwaysVibe.md)

人間とは、おおかた過去を美化するものである。
とかく昔というものに、苦行僧めいた金メッキを施したがる。
いにしえの数学者は紙とペンだけでたちどころに真理を悟り、
かつてのプログラマは誰もが、何かというと万物を一から手作りしていた、
というわけである。ところが今日では、AI/LLM の流行によって、
人はすっかりモデルの伝声管に成り下がったかに見える。
いわゆる「雰囲気（Vibe）流派」である。
だが、過去をじっくり味わい直してみれば分かる。
数学ハンドブックをめくることから、コードスニペットを書き写すことまで、
大半の人間は実のところ、一度たりとも Vibe から抜け出したことがないのである。

試みに、ソフトウェアエンジニアリングを例に取ろう。

- かつて、人は Google や StackOverflow の検索欄にプロンプトを打ち、
  使えそうなコードスニペットが釣れることを祈った。運が良ければ、
  見つけたスニペットに少しばかり手を加えた。
- いま、人は `gpt-6-astra` のような最先端モデルのチャット欄にプロンプトを打ち、
  使えそうなコードスニペットが生成されることを祈る。願いが叶わなければ、
  打ったプロンプトに少しばかり手を加えて、また祈る。

ともあれ、こうした「努力」の甲斐あって、たいていの場合、
最後にはプロジェクトにねじ込んで、めでたくリリースにこぎつけられる。
なにしろ……人間とコード、どちらかが走ればそれでよいのだから。

なるほど身も蓋もない現実ではある。だがそれは奇しくも、
研究室でやっていけないのではと怯えていた当時の私に、
mingkuang 先輩がかけてくれた慰めの箴言と響き合っている。
「アイデアを持っていることのほうが、技術力よりずっと大事だよ」と。
振り返ってみれば、私がこれまであれこれいじり回してきた、
いわゆる「有名プロジェクト」なるものに、0 から 1 を生み出したものは、
ほとんど一つもない。二つの小さなツールを一つにまとめた NSudo から、
自ら絵に描いた大きな餅を本物にすべく、7-Zip を土台に築いた NanaZip に至るまで、
いずれも 1 から N の範疇に属する。数学の予想であれ、
オープンソースのプロジェクトであれ、出発点ではたいてい巨人の肩の上に立っている。
だが、良心に恥じることなく最後まで形にしたいのなら、
数学者の厳密にして簡潔な論理的証明、あるいはソフトウェア開発者の、
極致への追求と匠の心による磨き上げが、結局のところ欠かせない。

ゆえに私の見るところ、AI/LLM が流行ろうと流行るまいと、
日はまた昇り、すべて世は事もなし。腰を据えて磨き上げようとする者は、
たとえ最先端モデルを手にしていようとも、あの匠の心と畏敬の念を失いはしない。
一方、お茶を濁してやり過ごせればよいという者は、
たとえ AI のない時代に送り返されたとしても、おおかた、
やはりあの一言に行き着くのだろう。
「人間とコード、どちらかが走ればそれでよい」と。
