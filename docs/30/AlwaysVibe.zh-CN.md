# 被神化的“手搓时代”：我们大抵一直活在 Vibe 之中

[English](AlwaysVibe.md)

人类大抵是美化往昔的，总爱给过去镀上一层苦行僧式的金身：
昔日的数学家仅凭纸笔便能顿悟真理，从前的程序员皆是一言不合手搓万物；
然而到了今天，AI/LLM 的流行却似乎让人完全堕落成了模型的传声筒，即所谓的
“氛围（Vibe）流派”。但若细细品味过往便能发现，从翻阅数学手册到抄录代码片段，
大部分人其实从未脱离过 Vibe。

不妨以软件工程为例：

- 过去，人们在 Google 或 StackOverflow 的搜索框里输入一段 Prompt，
  祈求能捞出一段合用的代码片段；若运气尚可，便将找来的片段做些许微调。
- 现在，人们在诸如 gpt-6-astra 等顶级模型的对话框里输入一段 Prompt，
  祈求能生成一段合用的代码片段；若未能如愿，便对输入的 Prompt
  做些许微调继续祈求。

总之通过这样的“努力”，大部分情况下最终都能塞进项目里成功上线。
毕竟嘛……人类和代码，只要有一个能跑就行。

诚然，这骨感的现实，却也暗合了当年我因惧怕在实验室混不下去时，
前辈老鸭子宽慰我的那句箴言：“有想法，比技术能力重要太多了。”
回望过往我折腾出的那些所谓“知名项目”，几乎没有一个是从 0 到 1 的：
从把两个小工具合二为一的 NSudo，到基于 7-Zip 画完自己大饼的 NanaZip，皆属从
1 到 N 的范畴。无论是数学猜想还是开源工程，起步时大多站在巨人的肩膀上；
但若想问心无愧地最终落地，终究离不开数学工作者严密而简洁的逻辑证明，
或是软件开发者对极致的追求与匠心打磨。

所以在我看来，无论 AI/LLM 流行与否，太阳照常升起，世间万物依然如常。
愿意潜心打磨的人，纵使手握顶级模型，亦不会失了那份匠心与敬畏；
而只求糊弄过关的人，即便退回没有 AI 的年代，
大抵也还是那句“人类和代码，只要有一个能跑就行”。
